# SignConnect — Real-Time AR Translation


**SignConnect** is a real-time augmented reality (AR) system that enables seamless, two-way communication between deaf/mute individuals and hearing users by translating **sign language to text** and **speech to text** instantly.

---

## Problem Statement

Deaf and mute individuals often face significant communication barriers when interacting with people who do not understand sign language. This limitation can lead to social isolation and difficulty accessing essential services such as healthcare, government offices, retail environments, and public spaces.

---

## Solution Overview

SignConnect is an **AR-based translator** that:
- Converts **sign language gestures into text** for hearing users
- Converts **spoken language into text** for deaf/mute users
- Enables **natural, real-time, two-way communication** without requiring a human translator

The system prioritizes accessibility, independence, and inclusivity.

---

## Key Goals

- Real-time communication with minimal latency  
- Inclusive and barrier-free interaction  
- Two-way translation (Sign → Text, Speech → Text)  
- Independence for deaf/mute users  
- Increased awareness and accessibility through AR  

---

## Target Users

- Deaf individuals  
- Mute individuals  
- Hearing users unfamiliar with sign language  

---

## ⚙️ Core Features

### Sign Language → Text
- AR-based hand tracking captures gestures in real time
- Recognized gestures are translated into readable text
- Text is displayed instantly for the hearing user

### Speech → Text
- Hearing user speaks naturally
- Speech is converted to text using speech recognition
- Text is displayed clearly for the deaf/mute user

### Real-Time Interaction
- Both translation pipelines operate simultaneously
- Enables fluid, uninterrupted conversation

---

## System Workflow

1. Deaf/mute user performs a sign
2. AR hand tracking recognizes the gesture
3. Gesture is translated into text for the hearing user
4. Hearing user responds verbally
5. Speech is converted to text and displayed for the deaf/mute user

---

## User Testing & Feedback

User testing was conducted with multiple participants using AR headsets.

### Observations:
- **Speech-to-text accuracy** rated as accurate to very accurate
- **Ease of use** rated easy by the majority of users
- Both translation modes were found equally useful

### Feedback Highlights:
- Users requested support for **more signs**
- Adaptation for users of **different heights and body proportions**
